[launch.usage]
Usage : {1}/liltress <commande>

  configure   prépare global.conf et secrets.conf
  check       vérifie ces deux fichiers
  run         installe (root)
  lynis       audit Lynis (root)
  logs        copie les journaux
  vpn         tunnel WireGuard ou OpenVPN (root)
  verify      contrôle le produit installé (root)
  maintain    recalcule une base ou rejoue un entretien (root)
  timer       lance un contrôle planifié du poste (root)
  cron        lance un contrôle planifié du serveur (root)
  install     prépare les paquets ou le clone
  help        cette aide
