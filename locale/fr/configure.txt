[configure.usage.server]
Usage :
  sudo ./liltress configure           questions, puis le profil, puis l'installation
  sudo ./liltress configure --basic   nom du projet + domaine ; le reste est calculé
  sudo ./liltress configure --avance  toutes les questions, sauf le profil serveur
  ./liltress check                    vérifie les deux fichiers, code 0 si conformes

Le profil serveur (MATRIX, LIVEKIT, WIREGUARD) est demandé au début de l'installation.

Exemples de valeurs :
  PROJECT_NAME             Liltress
  DOMAIN                   example.com
  MAIN_USER                drawbridge
  SSH_PORT                 2501
  MODE_TEST                0 (production) ou 1 (debug sans Certbot)
  MODE_DEV                 1 (portail local) ou 0 (images GHCR)
  POSTFIX_MAIL_ADDRESS     toi@exemple.com          (From, si alertes)
  POSTFIX_MAIL_SMTP        smtp-mail.outlook.com:587
  WATCHDOG_MAIL            la même adresse que From
  TURNSTILE_SITE_KEY       0x4AAAAAAAxxxxxxxxxx    (profil MATRIX)
  POSTGRES_WEB_PASSWORD          openssl rand -hex 32    (profil MATRIX, ou GEN)

Les mots de passe machine (root, SSH, Postgres synapse, Keycloak, htpasswd)
ne sont pas saisis ici. L'installateur les génère. Avec les alertes, il les
envoie à From. Sans les alertes, il les ajoute à /root/liltress-credentials.txt.
L'envoi vers Google Drive est au choix. Coupé, rclone n'est pas installé.
