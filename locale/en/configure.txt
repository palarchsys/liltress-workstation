[configure.usage.workstation]
Usage:
  sudo ./liltress configure          questions, then the installation
  ./liltress check                   checks the files, code 0 when they conform

The Ubuntu Pro token is required. Email alerts are optional.
The copy to Google Drive is optional. When it is off, rclone is not installed.
A password is shown as asterisks, then a second line asks for confirmation.

[configure.usage.server]
Usage:
  sudo ./liltress configure           questions, then the profile, then the installation
  sudo ./liltress configure --basic   project name + domain; the rest is calculated
  sudo ./liltress configure --avance  every question except the server profile
  ./liltress check                    checks the two files, code 0 when they conform

The server profile (MATRIX, LIVEKIT, WIREGUARD) is asked at the start of the installation.

Example values:
  PROJECT_NAME             Liltress
  DOMAIN                   example.com
  MAIN_USER                drawbridge
  SSH_PORT                 2501
  MODE_TEST                0 (production) or 1 (debug without Certbot)
  MODE_DEV                 1 (local portal) or 0 (GHCR images)
  POSTFIX_MAIL_ADDRESS     you@example.com          (From, if alerts)
  POSTFIX_MAIL_SMTP        smtp-mail.outlook.com:587
  WATCHDOG_MAIL            the same address as From
  TURNSTILE_SITE_KEY       0x4AAAAAAAxxxxxxxxxx    (MATRIX profile)
  POSTGRES_WEB_PASSWORD          openssl rand -hex 32    (MATRIX profile, or GEN)

Machine passwords (root, SSH, Postgres synapse, Keycloak, htpasswd)
are not typed here. The installer generates them. With alerts, it sends
them to From. Without alerts, it appends them to /root/liltress-credentials.txt.
