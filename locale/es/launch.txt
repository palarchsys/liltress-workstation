[launch.usage]
Uso: {1}/liltress <orden>

  configure   prepara global.conf y secrets.conf
  check       comprueba esos dos archivos
  run         instala (root)
  lynis       auditoría Lynis (root)
  logs        copia los diarios
  vpn         túnel WireGuard u OpenVPN (root)
  verify      comprueba el producto instalado (root)
  maintain    recalcula una base o repite un mantenimiento (root)
  timer       lanza un control planificado del puesto (root)
  cron        lanza un control planificado del servidor (root)
  install     prepara los paquetes o el clon
  help        esta ayuda
