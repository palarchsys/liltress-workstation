[configure.usage.workstation]
Uso:
  sudo ./liltress configure          preguntas, luego la instalación
  ./liltress check                   comprueba los archivos, código 0 si son conformes

El token de Ubuntu Pro es obligatorio. Las alertas de correo son opcionales.
La copia hacia Google Drive es opcional. Desactivada, rclone no se instala.
Una contraseña se muestra con asteriscos, luego una segunda línea pide la confirmación.

[configure.usage.server]
Uso:
  sudo ./liltress configure           preguntas, luego el perfil, luego la instalación
  sudo ./liltress configure --basic   nombre del proyecto + dominio; el resto se calcula
  sudo ./liltress configure --avance  todas las preguntas, salvo el perfil del servidor
  ./liltress check                    comprueba los dos archivos, código 0 si son conformes

El perfil del servidor (MATRIX, LIVEKIT, WIREGUARD) se pide al inicio de la instalación.

Ejemplos de valores:
  PROJECT_NAME             Liltress
  DOMAIN                   example.com
  MAIN_USER                drawbridge
  SSH_PORT                 2501
  MODE_TEST                0 (producción) o 1 (depuración sin Certbot)
  MODE_DEV                 1 (portal local) o 0 (imágenes GHCR)
  POSTFIX_MAIL_ADDRESS     usted@example.com          (From, si hay alertas)
  POSTFIX_MAIL_SMTP        smtp-mail.outlook.com:587
  WATCHDOG_MAIL            la misma dirección que From
  TURNSTILE_SITE_KEY       0x4AAAAAAAxxxxxxxxxx    (perfil MATRIX)
  POSTGRES_WEB_PASSWORD          openssl rand -hex 32    (perfil MATRIX, o GEN)

Las contraseñas de la máquina (root, SSH, Postgres synapse, Keycloak, htpasswd)
no se escriben aquí. El instalador las genera. Con alertas, las envía a From.
Sin alertas, las añade a /root/liltress-credentials.txt.
La copia hacia Google Drive es opcional. Desactivada, rclone no se instala.
